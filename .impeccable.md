# Impeccable Design Context

## Design Context

### Users
Book club members (25 per club) who participate in a monthly cycle of nominating, voting on, reading, and reviewing fantasy & sci-fi books. Many members can't attend every in-person meeting — the platform ensures they can still participate meaningfully through nominations, votes, reviews, and reactions. The broader vision (GatherBound) extends this to any in-person cultural club. Users arrive looking for what the club is reading now, wanting to cast a vote, or reflecting on a past pick.

### Brand Personality
**Archival, Warm, Editorial** — the interface feels like a beautifully kept club journal. It's a curated cultural record with quiet warmth, never a dashboard or social feed. The "First Edition" aesthetic draws from independent bookstore catalogs and literary publications.

### Emotional Goals
The primary emotion is **quiet pride and belonging** — "I'm part of something worth recording." Members should feel like they're opening a living archive of shared literary experiences, not logging into an app.

### Aesthetic Direction
- **Visual tone**: Sparse, editorial, monochrome with content-provided color. Book covers are the primary source of visual energy. The UI itself is nearly colorless — black text, gray metadata, white surfaces.
- **References**: record.club (archival music logging), Apple Books (clean editorial layouts), Letterboxd (social logging with editorial feel and community energy)
- **Anti-references**: Goodreads (cluttered, data-heavy), gamified reading apps, anything with "app energy" instead of editorial energy
- **Theme**: Light mode primary, dark mode supported via dual-selector pattern (OS preference + manual toggle)
- **Typography**: Serif headlines (DM Serif Display) for editorial authority, Fraunces for hero book titles, Source Serif 4 italic for author names, Inter for body/UI, IBM Plex Sans for badges/labels
- **Color philosophy**: Near-zero UI color. Pure white (#FFFFFF) background. Amber (#b45309) and teal (#0f766e) used sparingly. Gold (#F5A623) for star ratings only. Book cover imagery provides all visual richness.

### Design Principles
1. **Artifact Over Interface** — Content dominates, UI recedes. Every page should feel like a published page, not a software screen. The book cover, the review, the vote result — these are the artifacts. The chrome disappears.
2. **Quiet Confidence** — Minimal visual noise, intentional spacing, no gratuitous decoration. Generous whitespace between sections, efficient density within components. The design earns trust through restraint.
3. **Ritual Over Feature** — Design reinforces the club lifecycle: Nominate → Vote → Read → Discuss → Reflect → Archive. Each phase has its own interaction energy (frictionless nomination, tactile voting, reflective reviewing, communal results).
4. **The Room Is Always Bigger** — Every design decision should ask: can a member who never attends a meeting still engage meaningfully? Participation shouldn't require a seat.
5. **Editorial, Not Dashboard** — Information is narrated, not tabulated. Pages answer one story question at a time. Stats exist to celebrate, not to optimize.

### Accessibility
- WCAG AA compliance (contrast ratios, keyboard navigation, screen reader support)
- Dark mode with FOUC prevention (inline script sets theme before first paint)
- Semantic HTML with appropriate ARIA attributes
- Focus-visible indicators for keyboard navigation

### Technical Constraints
- Zero build-step: vanilla CSS + JS, no bundler, no framework
- Three-file CSS architecture: tokens.css → base.css → components.css
- 8pt spacing grid with defined scale (4px–80px)
- Max content width: 860px, single centered column
- Cache-busted via query strings on CSS links across all 4 shell layouts
